# MaksX

Личный бренд: YouTube-канал «Баг в прошивке», нейросети, сайты, AI-агенты, автоматизация n8n. Полный брендбук: https://claude.ai/artifact/R4E1q9jhcCsHXaWXZqQXwu

## Файлы

| Файл | Где использовать |
| --- | --- |
| `logo/maksx-logo.svg` | Шапка сайта на тёмном фоне (основной вариант) |
| `logo/maksx-logo-light.svg` | Шапка на светлом фоне, документы, КП |
| `logo/maksx-logo-channel.svg` | Первый экран, баннеры, превью: логотип с «БАГ В ПРОШИВКЕ» |
| `logo/maksx-mark.svg` | Фавиконка, аватарка, водяной знак |
| `logo/png/maksx-logo*.png` | Те же логотипы в PNG, прозрачный фон, 4x (880 px и шире): соцсети, презентации, документы, конструкторы сайтов |
| `logo/png/maksx-mark-512.png`, `-180.png`, `-32.png` | Знак: аватарка (512), иконка на телефоне apple-touch-icon (180), фавиконка (32) |
| `colors/brand.css` | Цвета, отступы, скругления. Тёмная тема по умолчанию, светлая - `<html data-theme="light">` |
| `fonts/fonts.css`, `fonts/fonts.html` | Montserrat (логотип, заголовки) и Onest (текст) |

## Правила для сайта

- Тёмная тема по умолчанию: фон `--night`, карточки `--night-raised`, текст `--ink`, подписи `--ink-muted`.
- Кнопка действия - фон `--bug`, текст `--on-bug`, скругление `--radius-pill`.
- Крупные плашки и превью - `--glass`, текст на нём `--on-glass`.
- Жёлтый `--volt` - одно пятно на экран: главная цифра или стикер. Текст на нём `--on-volt`.
- На `--glass` зелёная «X» не читается: там логотип целиком светлый.
- Заголовки - Montserrat 700-800, текст - Onest. Выравнивание по левому краю, строка до 65 знаков.
- Тени не используются, объекты разделяются тоном фона.
- Только короткое тире «-». В контенте на «ты», в услугах и КП на «вы».
